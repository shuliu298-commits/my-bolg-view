# 个人博客前端页面

这是一个简洁的个人博客首页，使用原生 HTML + CSS + JavaScript 实现，适合作为个人博客的起始模板。

## 页面内容

- 顶部导航（关于我 / 文章 / 联系）
- Hero 区域（博客定位、简介与按钮）
- 关于我模块
- 最新文章列表模块
- 联系方式模块
- 页脚年份自动更新

## 本地运行

在项目根目录执行：

```bash
python3 -m http.server 4173
```

然后打开浏览器访问：

```text
http://localhost:4173
```

## 文件结构

```text
.
├── index.html   # 页面结构
├── styles.css   # 页面样式
├── script.js    # 简单交互（年份）
└── README.md
```
